Privacy Policy — commentagent

Last updated: July 2026

This application ("commentagent") is a testing/development tool built for managing Instagram comment interactions via the Instagram Graph API.

Data We Access

Instagram comments on posts belonging to connected accounts, and basic profile information (username) associated with those accounts.

How We Use It

To read comments and generate automated replies using AI. We do not sell, share, or use this data for advertising purposes. We do not store comment data beyond what is necessary for reply generation.

Data Retention

Access tokens are stored securely and only used to interact with the connected Instagram account. Users may revoke access at any time via their Instagram/Facebook account settings.
